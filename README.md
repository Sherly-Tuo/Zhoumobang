# 周末帮 · 大学生周末兼职撮合平台（交互 Demo）

纯前端单文件 Demo（`index.html`），手机模型机界面，美团黄黑视觉风格。无需构建，直接部署到 GitHub Pages。

## 部署
1. 新建 GitHub 仓库，上传 `index.html` 和本 README
2. Settings → Pages → Source 选 `main` 分支 / root → Save
3. 访问 `https://<用户名>.github.io/<仓库名>/`

## 体验路径
- 桌面点「周末帮」→ 启动页 → 选身份免密登录
- 学生端：兼职（推荐 / 分类 / 筛选 / 详情 / 报名）· 日程（签到 → 完工 → 到账）· 消息 · 我的（空闲时间、技能、简历）
- 商家端：工作台（数据 / 岗位进度）· 候选人（匹配度、信用分、录用 / 婉拒）· 发布（AI 生成描述、薪资托管）· 消息 · 我的
- 「我的」页可切换身份：商家发布的岗位会出现在学生端，学生报名商家岗位后商家端可录用
